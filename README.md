# 🍻 Brew Clone - Веб-планировщик производства

🔗 **Живая демонстрация (Live Demo):** [https://my-brew.ru](https://my-brew.ru)

Сервис для планирования и управления производственными процессами на пивоварне. 
Проект помогает отказаться от бумажных журналов, автоматизирует расчет ресурсов и наглядно отображает этапы работ.

## ✨ Основной функционал
*   **Интерактивная диаграмма Ганта:** Визуализация этапов варки и задач.
*   **Управление складом:** Учет остатков ингредиентов и готовой продукции.
*   **Калькулятор рецептов:** Расчет плотности, IBU и других параметров.
*   **Учет ресурсов:** Контроль загрузки оборудования и персонала.

## 🛠 Технологический стек
*   **Frontend:** React.js, Vite, JavaScript (ES6+), CSS3.
*   **Backend:** Node.js, Express.js.

## 📂 Структура проекта
*   `client/` — клиентская часть (React-приложение).
*   `server/` — серверная часть (Node.js API).
